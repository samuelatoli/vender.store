# Vender Store

Simple Flask app for vendors to upload product details (name, description, contact, price) and an optional image. Uses SQLite for storage.

## Setup (Windows)

```powershell
python -m venv venv
venv\Scripts\Activate.ps1    # or venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 in your browser.
